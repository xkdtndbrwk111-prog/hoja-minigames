# 붕어빵 핫픽스 — 줄무늬 가판 손 앵커 + 2·4인 협동 업그레이드 (2026-11-23)

## 현장 사진으로 확정한 기준
- 캐릭터가 잡는 대상은 나무색 계산대가 아니라 **고객 바로 아래의 빨강/하양 반복 줄무늬 막대**.
- `shBuildBg()`의 줄무늬 상단은 `SH.TZ-34`, 나무 카운터 시작점은 `SH.TZ`.
- 기존 수정은 앵커를 `TZ+8` 정도로 잡아 손이 줄무늬 아래에 걸침. **새 목표 = `TZ-34 + 최대 8`**, 즉 줄무늬 막대 윗부분에 팔을 얹은 형태.
- 가판대→캐릭터 렌더링 순서를 유지하고, 35종 초상화 알파 앵커의 세로 좌표를 사용. 표정별 x 흔들림은 중립 표정 중심을 기준으로 방지.
