# HOJA 붕어빵 2·4인 협동 — 10초마다 바뀌는 실시간 업그레이드 (설계 후보, 2026-11-23)

## 0. 범위·정본 근거
- 현재 운영 소스: `src/js/bakery.js`.
- 싱글 업그레이드 `SH_UP`: molds, fire, price, patience, tray, gold, burn, special.
- 협동 모드 `co2`, `co4`: 120초 경기, 공용 4역할(반죽/굽기/포장/계산); 계산 담당은 `shDrawCo`의 ④ 열, 계산 대기 카드 최대 3장.
- 기존 `SH.money`은 판매로 증가하는 가용 게임 자금, `SH.earned`는 누적 매출/별 및 협동 명예의 전당 산정 기준.
- 현행 `shMakeBag`은 기본 500원 고정으로 거스름돈 문제 생성. `shSpecial`은 협동에서 사용하지 않도록 막혀 있음.
- **이번 작업은 설계만 승인 대기. 구현 및 게임 규칙 변경은 별도 PR로 진행.**

## 1. 핵심 UX
- 2인·4인 **협동**의 ④ 계산 담당 열 아래쪽에 소형 업그레이드 카드 1개 표시. 1대1 대결/싱글은 기존 동작 유지.
- 카드에는 [오늘의 업그레이드], 상품명, 효과 한 줄, 가격, 팀 공동 가용 잔액, 다음 교체까지 남은 시간(막대 + 초) 표시.
- 구매 가능할 때만 강조. 구매 후 카드 내용은 [구매 완료]로 잠금, 다음 10초 주기에 새 상품. 상품이 품절이면 다시 랜덤 추첨.
- 경기 시작 시 첫 제안, 이후 유효 **플레이 시간** 10초마다 1종 교체(0,10,...110초). 일시정지·카운트다운·결과 화면에서는 교체 중단. 120초 종료로 닫음.
- 6종을 섞은 셔플 백에서 무작위 추첨: 연속 중복 방지, 한 바퀴 안에 가능한 모든 후보 1회 노출, 구매·최대 단계 도달 시 후보 제외.
- 멀티터치 오입력 방지를 위해 0.35초 누르기 후 확정(또는 게임 테스트에서 더 쉬운 2단계 선택으로 대체). 손가락이 영역 밖으로 벗어나면 취소. 갱신 순간에는 `offerId`/`slotIndex`를 재검증해 지난 화면 터치가 새 상품을 사지 않도록 함.
- **절대 우선순위: 계산 담당의 거스름돈 3개 대기 카드와 각 카드의 3개 정답 선택 버튼을 유지. 업그레이드를 위해 계산 카드를 2장으로 줄이거나, 정답 버튼을 축소·클리핑·스크롤 뒤로 숨기지 않는다.** 고객 주문·포장·반죽, 하단 메뉴/시계 터치 영역도 불변.
- 기존 ④ 계산 카드 영역을 먼저 확보하고, 남는 높이에만 하단 1줄형 업그레이드 띠를 배치한다. 표기 최소화: `업그레이드명 · 가격 · 남은 초 · 구매`. 상세 설명·팀 잔액은 필요할 때 별도 작은 안내로 표시하여 계산 영역을 침범하지 않는다.
- 카드 3장 × 거스름돈 선택 버튼 3개가 실제 화면에서 전부 보이고 버튼 터치 크기(최소 44×44 실제 CSS px)와 숫자 가독성이 유지될 때만 업그레이드 띠의 높이를 할당한다. 부족하면 계산 영역은 그대로 보존하고 업그레이드는 높이가 낮은 접이식 탭 + 탭으로 여는 별도 확인창으로 표시한다. 확인창은 `닫기`가 명확하고 구매·취소 시 즉시 닫히며, 계산 중 터치를 가로채지 않아야 한다.
- 계산 카드와 업그레이드 히트 영역은 반드시 분리. ④의 계산 선택지 위에 구매 버튼을 띄우거나 보이지 않는 오버레이로 덮지 않는다.

### ④ 계산 담당 고정 배치안 (화면이 충분할 때)

```text
┌─────────────── ④ 계산 담당 ───────────────┐
│ 계산 대기 1  ·  거스름돈 [A] [B] [C]        │
│ 계산 대기 2  ·  거스름돈 [A] [B] [C]        │
│ 계산 대기 3  ·  거스름돈 [A] [B] [C]        │
├─────────────────────────────────────────────┤
│ ⚡ 센 불  2,500원   다음 07초     [구매]     │
└─────────────────────────────────────────────┘
```

- 이 도식은 **시각적 우선순위와 순서**를 나타내며 확정 픽셀 배분은 아니다. 3개 계산 카드/9개 정답 선택지의 가용 공간을 먼저 측정하고, 아래의 업그레이드만 그 남는 영역에 넣는다.
- 좁은 화면에서는 단일행을 `⚡ 업그레이드 07초 [열기]`로 접되 계산 인터랙션을 덮지 않는다. 10초 순환과 구매 가능 상태는 접이식에서도 유지.

## 2. 최초 밸런스 수치 (운영 수치는 테스트 후 조정)

| 싱글 원본 | 협동용 노출명 | 비용 | 협동 효과 | 상한 |
|---|---|---:|---|---|
| molds | 붕어빵 틀 +1 | 3,000원 | 공유 굽기 틀 4 → 5개. 공간 문제로 +2 대신 +1 | 1회 |
| fire | 센 불 | 2,500원 | 기본 조리시간 3.2초의 15% 단축 | 1회 |
| patience | 친절 교육 | 2,000원 | 새 손님 기다림 20% 증가, 현재 손님은 이미 지나간 시간 대신 남은 시간만 20% 보정 | 1회 |
| tray | 넓은 완성대 | 1,800원 | 공유 완성대 8 → 10개 | 1회 |
| gold | 황금 손맛 | 2,200원 | 황금 타이밍 1.0 → 1.5초 | 1회 |
| burn | 약한 불 조절 | 1,500원 | 타기 전 여유 3.0 → 3.5초 | 1회 |

- 4인 협동은 표의 기준 가격, 2인 협동은 처리량·손님 간격 차이를 감안해 **20% 할인(100원 단위 반올림)**하는 초안. 실제 구매율·별 획득률 시험 후 최종 확정.

### 제외
- `price` 가격 +100원: 협동 계산 문제의 지불 금액은 `shMakeBag`에서 개당 500원으로 생성되지만, 매출 `shPrice`만 올리면 표기·거스름돈 정답과 실제 지급액이 불일치함. 별도 정산 구조를 새로 설계하기 전에는 제외.
- `special` 필살기 강화: 기존 필살기는 캐릭터 및 단독 플레이 기준, `shSpecial`은 `SH.co`에서 차단함. 협동에 적용하면 작업 분담과 역할 균형이 깨져 제외.

## 3. 경기·점수 정책
- 업그레이드 구매는 붕어빵 **경기 내 가상 매출 자금** `SH.money`에서만 차감. 학생 계정 호자 코인·주급·실제 화폐는 관여하지 않음.
- 협동 명예의 전당·목표 별 1·2·3개는 `SH.earned` (총 누적 매출) 기준 유지. 업그레이드 지출로 벌어들인 매출/별이 줄어들지 않음.
- 구매 효과는 그 **120초 경기 한 판**만 유지하고 즉시 시작. 재대결·다른 게임 시작 시 초기화.
- 협동 업그레이드 상태는 `SH.co.up`에 별도 관리. 싱글의 `SH.up` 및 `shDrawUpgrades` 5일 장사 상점은 불변.
- 협동 모드에서만 `shCookTime, shPatienceMul, shGold, shBurn, shTrayCap`의 읽기 분기를 확장. 틀을 살 때 `s.molds`에 1개 추가하여 기존 `shMoldGrid` 5개 배치 활용.
- 계산 담당이 구매를 독점할지, 2인 모드에서 어느 학생이 계산역을 맡는지 기존 4역할 UI에 맞게 사용성 확인.

## 4. 시간/오동작·성능·테스트
- `SH.time` 기반 10초 슬롯 산정. 일시정지, 네트워크 지연, 30/60fps, 백그라운드 복귀 시 한 슬롯에서 여러 번 지급/추첨 불가.
- 잔액 부족/구매 완료/최대 단계에서 터치 무시, 짧은 시각·음향 피드백만 제공. 10초가 끝나기 직전 누른 상황의 새 상품 오구매 금지.
- 최우선 자동 테스트: **동시 계산 대기 3장 × 선택지 3개(총 9버튼)**가 어떤 업그레이드 상태에서도 표시·터치 가능하며, 텍스트가 잘리거나 계산 버튼이 업그레이드에 가려지지 않는다. 2장만 보이게 하거나 스크롤을 강제하는 해결책은 금지.
- ④ 계산 카드 높이와 정답 터치 크기를 기준으로 동적 높이를 계산한다. 공간이 부족한 경우 업그레이드 카드부터 한 줄/접이식으로 축소하고, 그 다음에도 불가능하면 기존 계산 레이아웃을 보존하는 별도 구매 확인 화면으로 전환한다. **거스름돈 카드/버튼 크기가 업그레이드 때문에 감소하는 방향의 대응은 불허.**
- 업그레이드 후보가 10초마다 바뀌어도 계산 버튼 위치는 고정. 구매 확정·취소 시 계산 대기 데이터와 선택 포커스, 멀티터치가 유지되는지 검사.
- 점수/거스름돈/기존 필살기/싱글 업그레이드/2인 장사 대결/환불에 영향 없음.
- 1920×1080, 1366×768, 1024×768 및 85인치 전자칠판 실터치에서 텍스트/클릭 영역/구매 중복/최소 버튼 높이 검증.
- 120초 랜덤 후보 노출 횟수, 불리한 RNG, 실구매율, 목표 별 달성률, 회차별 구매 효과를 고정 시드 테스트.
