# 붕어빵 가판대 손 앵커 정렬 (2026-11-23)

## 현장 피드백
- 손님 캐릭터 7종의 손·앞발이 가판대 상단 테두리에서 떨어져 공중에 떠 보임.
- 기존 초상화의 투명 여백이 이미지마다 달라 일괄 사각형 기준으로 그리면 위치가 맞지 않음.
- 캐릭터 원본 이미지 수정 없이, 가판대보다 앞 레이어에서 손이 테두리를 살짝 덮도록 표현.

## 코드 조사
- 가판대 배경은 `shBuildBg()`에서 Y=`SH.TZ`를 기준으로 먼저 캐시한 뒤 `shDraw()`에서 렌더링됨.
- 고객은 `shDrawCustomers()`에서 그다음 그려짐. **기존 순서에서 가판대 뒤가 아니라 앞 레이어이며, 별도 그림 에셋이 필요하지 않음.**
- 기존 코드는 그림의 `size×size` 사각형 하단을 `TZ-40`에 배치하여 실제 불투명한 손 위치가 가판대에서 떨어짐.
- 무한의 계단의 `stPortraitAnchor()`는 투명도 128 이상인 픽셀의 실루엣 하단과 좌우 중심을 계산해 `WeakMap`으로 캐시함. 동일 빌드의 공유 함수를 재활용.

## 적용
- [x] 붕어빵 고객을 이미지 사각형이 아닌 실제 알파 실루엣 앵커로 배치.
- [x] 가판대 상단보다 최대 9 가상 좌표 픽셀 아래에 실제 손·발 하단이 오도록 함 (가판대 앞쪽으로 약간 겹침).
- [x] 표정별 실루엣의 세로 앵커를 쓰고, 좌우 기준은 중립 표정 이미지의 중심으로 고정하여 표정 변화 시 좌우 흔들림 완화.
- [x] 기존 입장·퇴장 애니메이션 이동량과 고객 말풍선·주문 정보는 유지.
- [x] 싱글, 2인 대결, 2·4인 협동의 공유 `shDrawCustomers`에만 제한 적용.
- [x] 초상화 WebP 이미지 및 게임 조작부·가판대 배경 원본 수정 없음.
- [x] 단위 시험: 레이아웃·공유 앵커·레이어 순서·빌드 일치.
- [x] 실제 7종×5개 표정 = 35개 이미지의 투명도 앵커를 검사하는 브라우저 시험 추가.
