# 명예의 전당 계열별 묶음 및 번개미션 연동 — 2026-11-13

## UI 개편
- 여러 종목으로 구분돼야 공정한 게임을 **하나의 게임 카드**로 묶어 표시한다.
- 무한의 계단: 1인전 / 다인전
- 호자 점프: 1인전 / 2인전
- 붕어빵 가게: 1인 5일 총매출 / 2인 대결 / 2인 협동 / 4인 협동
- 번개미션: 혼자 도전 / 8판 대결 / 12판 대결
- 에어하키, 호자 배구, 퍼즐버블, 오셀로, 오목, 틱택토, 세균전, 파티 랠리는 단일 카드로 유지.
- 카드의 모드 제목과 Top 3 점수를 구분하고, 너비가 부족할 때 자동으로 다음 줄로 내린다.

## 새 번개미션 점수 규칙
- 혼자 도전 `flash_solo`: 목숨 3개가 소진되면 성공한 총 미션 개수 기록
- 8판 대결 `flash_r8`: 최종 총점, **두 선수 각각** 저장 (최대 16점)
- 12판 대결 `flash_r12`: 최종 총점, **두 선수 각각** 저장 (최대 24점)
- 서버 각 모드의 최고 1회 기록(MAX(score))을 집계. 다른 길이의 모드 점수는 섞지 않는다.
- 학급 연결 시 코인 결제/선택으로 선수 구분을 하고, 미연결 게스트는 저장하지 않는다.
- 파티 랠리에 포함되어 일회성으로 등장한 번개미션은 별도 종목에 전송하지 않는다.
- 신규 종목은 기존 코인 보상 확대를 피하기 위해 순위만 표시하고 자동 지급은 하지 않는다.

## 구형 기록 리셋
- 혼합 규칙 때문에 재분류할 수 없었던 구형 `stairs`, `jump`, `shop` 종목을 UI 목록 및 서버의 새 기록 허용목록에서 제거.
- 적용 직전 구형 기록은 `stairs` 11건 / `jump` 0건 / `shop` 0건.
- 운영 DB에서 구형 기록 11건만 삭제 (삭제 후 해당 종목 0건 재확인).
- 새 규칙의 계단 다인전, 붕어빵 4인 협동 등과 모든 승리형 게임 기록은 보존.
- 이미 지급된 코인과 과거 결산 이력, 학급 및 학생 이름 정보 변경 없음.
- 앱에 저장된 구형 미전송 항목은 다음 실행 시 제거. 새 모드의 대기 기록은 유지.
